# 思源笔记日历面板插件

简体中文 \| [English](https://github.com/gradypark86/siyuan-plugin-calendar/blob/main/README_en_US.md)

一个思源笔记日历面板插件，可以快速创建日记/周记/月记/年记等周期笔记，支持模板自动加载。

![项目截图](https://imgs.pprain.space/2026/01/41d3d243f69952db7cf91a75d4963246.png)

## 主要功能

- 日历功能
  - 可选按钮入口位置
  - 可选显示周号
  - 可选每周开始日（周日/周一）
  - 可选周号规则（日历周/ISO 8601，位于高级设置；切换规则不影响已有周记）
  - 边栏模式下宽度缩放自适应
  - 点击日期可快速创建或跳转到该日期日记
  - 支持多笔记本切换
- 周期笔记功能
  - 可选开启周记功能，开启后点击周号可创建相应周周记，或在创建日记时自动创建当周周记
  - 支持自定义周记、月记、年记的创建位置与模板
- 自定义配置
  - 可设置新一天开始时间
- 支持全平台客户端
- 文档属性「一键补写」
  - v0.5.0 起，通过面板创建的周期笔记会自动写入文档属性。对于已写入属性的周期笔记，即使后续修改标题或存放位置，面板仍可通过属性定位并跳转到原有笔记。
  - 面板加载周号时优先通过文档属性判断周记是否存在；对于尚未补写属性的历史周记，点击对应周号时会尝试通过存放路径查找，并在找到后自动补写属性。
  - 「一键补写」会从 2025 年 1 月起按周、月、年遍历当前配置对应的存放路径，查找并补写周期笔记属性；随后通过常见存放路径格式进行正则扫描，尽可能覆盖更早创建或特殊命名的周期笔记。
  - 修改周期笔记存放位置或周号规则前，建议先运行「一键补写」，避免面板无法找到原有周记而新建空白周记。无法通过自动规则识别的自定义路径，可能仍需点击对应周期入口手动补写。
